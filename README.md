# Playwright E-Commerce Automation

## 📌 Overview

End-to-end **E-Commerce web application automation testing** using **Playwright, JavaScript, TypeScript, Cucumber, and Page Object Model (POM)**.

## 🛠️ Tech Stack

* Playwright
* JavaScript & TypeScript
* Cucumber (BDD)
* Page Object Model (POM)
* Node.js
* Git & GitHub

## 🧪 Test Scenarios

* Login
* Product Selection
* Add to Cart
* Checkout
* Place Order
* Order Confirmation
* Order History

## ▶️ Run Tests

```bash
npm install
npx playwright install
npx playwright test
```

### Run in Headed Mode

```bash
npx playwright test --headed
```
